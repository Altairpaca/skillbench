# v0.3 interoperability contract

v0.3 adds a portable execution-evidence boundary between SkillBench harness adapters and downstream evidence systems such as Agent Harness Index (AHI).

## Portable observation

`skillbench.harness-observation/v1` represents one attempted benchmark case/trial with explicit identity for:

- benchmark and optional benchmark version;
- case ID and trial index;
- harness ID/version;
- model ID and optional model version;
- exact skill source SHA-256;
- configuration and environment JSON;
- execution outcome and telemetry.

`latencyMs` is derived from `startedAt` and `finishedAt`; callers cannot supply an independent latency value through the constructor.

## Scoreability boundary

Only `pass` and `fail` are benchmark outcomes suitable for a binary success cell.

`error` and `skipped` remain first-class execution outcomes but are **not** equivalent to benchmark failure. A downstream consumer must keep them outside pass/fail score aggregation unless a different benchmark contract explicitly says otherwise.

## JSON boundary

Configuration and environment must satisfy SkillBench's strict canonical-JSON contract. Values such as `undefined`, non-finite numbers, non-plain objects and cyclic objects are rejected before portable evidence is produced.

## Cross-language bundle boundary

This release does **not** specify a cross-language reimplementation of `skillbench.bundle/v1` hashing. Bundle integrity remains verified by SkillBench's canonicalizer. A downstream language implementation may consume a verified `skillbench.harness-observation/v1` payload without claiming that it independently reproduced the bundle digest.

A future bundle schema may adopt a language-neutral canonical JSON standard if byte-identical hashing across runtimes becomes a requirement.

## Cloud-only acceptance

The v0.3 contract is fully testable with synthetic `HarnessRunEvidence` fixtures. No Codex, Claude Code, OpenCode, DSH, subscription credential or host-specific installation is required to establish these schema semantics.
